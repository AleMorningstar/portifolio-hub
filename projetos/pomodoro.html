PROJETO 01 — PRODUTIVIDADE

Pomodoro Focus

Uma aplicação de produtividade baseada na técnica Pomodoro, desenvolvida para auxiliar na organização de períodos de foco e descanso.

OBJETIVO

Foco durante os estudos

O projeto foi desenvolvido com o objetivo de criar uma ferramenta simples para controlar períodos de concentração e descanso durante os estudos.

DESENVOLVIMENTO

O que pratiquei

O projeto me permitiu praticar a construção de uma interface utilizando HTML e CSS, além da implementação de comportamentos e interações com JavaScript. Também trabalhei com a manipulação dos elementos da página para controlar o funcionamento do temporizador.

TECNOLOGIAS

Ferramentas utilizadas

HTML5 CSS3 JavaScript
APRENDIZADO

O que desenvolvi

Durante o desenvolvimento, trabalhei principalmente com estruturação de páginas, estilização com CSS e implementação de interações utilizando JavaScript.
