PROJETO 03 — ORGANIZAÇÃO

Registro de Atividades

Sistema desenvolvido para registrar atividades, seus níveis de complexidade e respectivas datas de entrega.

OBJETIVO

Organizar atividades

O projeto foi desenvolvido para facilitar o registro e acompanhamento de atividades, reunindo informações importantes em uma interface simples e organizada.

FUNCIONALIDADES

Registro de informações

A aplicação permite registrar o nome da atividade, seu nível de complexidade e a data relacionada à sua entrega.

TECNOLOGIAS

Ferramentas utilizadas

HTML5 CSS3 JavaScript
DESENVOLVIMENTO

O que pratiquei

O projeto permitiu praticar a criação de interfaces, organização de informações e implementação de interações utilizando JavaScript.
