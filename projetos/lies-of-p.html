PROJETO 02 — DESENVOLVIMENTO

Lies of P

Projeto de páginas inspirado no universo de Lies of P, desenvolvido para explorar composição visual, navegação e interação utilizando tecnologias web.

OBJETIVO

Construir uma experiência visual

O projeto foi criado para explorar a construção de uma experiência visual baseada na atmosfera de Lies of P, trabalhando composição, navegação e apresentação de conteúdo.

ESTRUTURA

Uma experiência por seções

A página principal apresenta informações sobre o jogo, a cidade de Krat e sua atmosfera, além de uma seção dedicada às músicas. O projeto também possui uma página separada para a expansão Overture.

TECNOLOGIAS

Ferramentas utilizadas

HTML5 CSS3 JavaScript
DESENVOLVIMENTO

O que estou praticando

O projeto permite praticar estruturação de páginas, estilização com CSS, navegação entre seções, transições visuais e utilização de JavaScript para criar comportamentos interativos.
