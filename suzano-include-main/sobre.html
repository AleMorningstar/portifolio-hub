SOBRE O PROJETO

Registro de Atividades

Uma aplicação desenvolvida para facilitar o registro e a organização de atividades.

01

Objetivo

O projeto foi desenvolvido com o objetivo de permitir o registro de atividades, seus níveis de complexidade e respectivas datas de entrega.

02

Organização

As atividades cadastradas são apresentadas em um painel, permitindo visualizar de forma simples as informações registradas.

03

Desenvolvimento

O projeto utiliza HTML, CSS e JavaScript para construir a interface, organizar os elementos e adicionar interação à aplicação.
